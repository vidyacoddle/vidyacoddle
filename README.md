## 🌟 What is Vidya?

Vidya Coddle Tech Consultancy builds custom IT solutions that actually ship and scale. We bypass legacy bottlenecks to engineer mission-critical platforms—including **ONDC nodes, FinTech settlement layers (VittaPe), and zero-downtime ERPs**. 

This repository houses our **flagship landing experience**: a blazingly fast, highly animated web platform designed with a pristine *minimal neomorphic* aesthetic.

## 🚀 Tech Stack

We believe in using the absolute cutting edge to deliver buttery-smooth, 60fps experiences on every device.

- **Framework**: [Next.js 16](https://nextjs.org) with Turbopack for instantaneous builds.
- **UI & Styling**: [Tailwind CSS v4](https://tailwindcss.com) featuring fluid typography (`clamp`) and custom glassmorphism.
- **Animations**: [Framer Motion](https://www.framer.com/motion/) for staggered spring layouts and scroll-triggered reveals.
- **3D Graphics**: [Three.js](https://threejs.org/) & [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber/) powering our signature rotating `LiquidGlass` canvas.
- **Icons**: Lucide React & Tabler Icons.

## ✨ Key Features

- **Liquid Glass 3D Hero**: A stunning, interactive WebGL hero background that reacts to the environment.
- **Fluid Typography**: Perfect mobile-first scaling without jarring breakpoint snaps.
- **Scroll-Triggered Bento Grids**: Performance metrics and industry domains spring to life as you scroll.
- **Infinite Ecosystem Marquee**: A seamless horizontal ticker showcasing our robust integration network.

## 🛠️ Getting Started

Want to run this masterpiece locally? It's easy!

### Prerequisites
Make sure you have `Node.js` (v20+) installed.

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/vidyacoddle/vidyacoddle.git
   cd vidyacoddle
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Experience the magic** ✨
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🎨 Design Philosophy

This project strictly adheres to a **Premium Minimal Neomorphism** aesthetic:
- **Canvas Base**: Soft Off-White (`#F7F3EA`) instead of harsh pure white.
- **Typography**: Dark Ink (`#1E1B16`) with subtle metallic text gradients.
- **Accents**: Our signature Signal Orange (`#FF5722`) to highlight interaction points and 3D emissions.
- **Depth**: Layers are defined by ultra-soft shadows (`bg-card`, `backdrop-blur-2xl`) rather than harsh borders.
